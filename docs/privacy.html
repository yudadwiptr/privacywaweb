Kebijakan privasi

Berlaku sejak 17 November 2026

Tirai adalah ekstensi browser yang menyamarkan isi WhatsApp Web dan bisa menguncinya dengan PIN. Kebijakan ini menjelaskan data apa yang dipakai Tirai dan di mana data itu disimpan.

Ringkasnya

  • Tirai tidak mengumpulkan, menjual, atau membagikan data pribadi.
  • Tirai tidak membaca, menyalin, atau mengirim isi chat WhatsApp.
  • Tirai tidak punya server, tidak memakai analitik, dan tidak memuat kode dari luar.

Data yang disimpan di browser kamu

DataTempatKegunaan
Pengaturan blur dan temachrome.storage.syncMengingat pilihanmu. Jika sinkronisasi browser aktif, pengaturan ini ikut tersinkron lewat akun browser kamu.
Hash PIN, salt, dan pengaturan kuncichrome.storage.localMemeriksa PIN saat membuka kunci. PIN asli tidak pernah disimpan, dan data ini tidak ikut tersinkron.
Waktu aktivitas terakhirchrome.storage.localMenentukan kapan WhatsApp Web dikunci otomatis.
Penanda "kunci aktif"localStorage web.whatsapp.comMenyembunyikan WhatsApp Web sejak halaman mulai dimuat, sebelum status kunci selesai dibaca. Isinya hanya angka 1.

Semua data di atas tetap berada di perangkat kamu dan terhapus ketika ekstensi dihapus.

Izin yang diminta

  • storage: menyimpan pengaturan dan hash PIN seperti dijelaskan di atas.
  • Akses ke web.whatsapp.com: memasang efek blur dan layar kunci. Tirai tidak berjalan di situs lain.

Pihak ketiga

Tirai tidak mengirim data ke pihak ketiga. Huruf dan ikon dibundel di dalam ekstensi, jadi membuka popup tidak memicu request ke luar.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan diterbitkan di halaman ini dengan tanggal berlaku yang baru.

Kontak

Pertanyaan atau laporan masalah bisa dikirim lewat GitHub Issues.

Tirai adalah proyek independen dan tidak berafiliasi dengan WhatsApp atau Meta.
