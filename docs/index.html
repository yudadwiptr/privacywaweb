Pilih sendiri apa yang ditutup

Setiap bagian WhatsApp Web bisa diburamkan sendiri-sendiri. Arahkan kursor ke bagian yang buram untuk melihatnya sebentar.

  • Isi pesan

    Semua gelembung chat di ruang obrolan, termasuk lampiran.

  • Pratinjau pesan terakhir

    Cuplikan pesan di daftar chat, jadi kabar baru tidak terbaca sekilas.

  • Foto dan video

    Media di dalam chat dan di galeri info kontak.

  • Kolom ketik

    Teks yang sedang kamu tulis tetap tertutup sampai kamu mengarahkan kursor.

  • Foto profil

    Foto kontak, grup, dan dirimu sendiri.

  • Nama kontak dan grup

    Di daftar chat dan di judul obrolan.

  • Tutup saat ditinggal

    Seluruh layar diburamkan setelah beberapa saat tanpa aktivitas.

  • Satu tombol untuk semua

    Buka atau tutup semua blur dengan Alt Shift B, dan atur ketebalannya sesuai selera.

Pergi sebentar? Kunci dengan PIN.

Saat terkunci, WhatsApp Web disembunyikan sepenuhnya di semua tab sampai PIN yang benar dimasukkan.

  • Kunci sekarang dari popup atau dengan Alt Shift L
  • Terkunci otomatis setelah 1 menit sampai 1 jam tanpa aktivitas
  • Terkunci lagi setiap kali browser dibuka
  • Setiap 5 kali PIN salah, percobaan ditahan dan jedanya terus bertambah
  • PIN tidak pernah disimpan, hanya hash-nya

Tirai tidak membaca, menyimpan, atau mengirim isi chat kamu. Tidak ada server, tidak ada analitik.

Hanya di WhatsApp Web

Ekstensi ini cuma berjalan di web.whatsapp.com. Situs lain tidak disentuh.

Cara kerjanya sederhana

Blur dipasang lewat CSS di browser kamu. Pesannya sendiri tidak pernah dibaca.

Kode terbuka

Semua kode bisa diperiksa di GitHub. Baca juga kebijakan privasi.

Pasang dalam semenit

Tirai sedang dalam proses peninjauan Chrome Web Store. Sambil menunggu, kamu bisa memasangnya langsung dari kode sumber.

  1. Unduh kode

    Buka repositori GitHub, pilih Code, lalu Download ZIP. Ekstrak ke satu folder.

  2. Buka halaman ekstensi

    Ketik chrome://extensions di address bar, lalu nyalakan Developer mode di pojok kanan atas.

  3. Muat Tirai

    Klik Load unpacked, pilih folder tadi, lalu buka web.whatsapp.com. Selesai.

Tanya jawab

Apakah Tirai membaca atau mengirim chat WhatsApp saya?

Tidak. Tirai hanya menambahkan efek blur lewat CSS di halaman WhatsApp Web. Tirai tidak membaca isi pesan, tidak punya server, dan tidak mengirim data ke mana pun.

Bagaimana cara melihat pesan yang diburamkan?

Arahkan kursor ke pesan, foto, atau nama yang diburamkan. Kamu juga bisa membuka atau menutup semua blur dengan Alt+Shift+B.

Apa yang terjadi kalau saya lupa PIN?

PIN tidak disimpan dalam bentuk asli, jadi tidak bisa dipulihkan. Hapus lalu pasang ulang ekstensi Tirai untuk mengatur PIN baru. Akun WhatsApp kamu tidak terpengaruh.

Apakah kunci PIN Tirai sama amannya dengan mengunci komputer?

Belum. Kunci PIN mencegah orang lain melihat WhatsApp Web saat kamu pergi sebentar, tapi orang yang paham bisa mematikan ekstensi lewat pengaturan browser. Untuk perlindungan penuh, kunci juga komputer kamu.

Browser apa saja yang didukung?

Google Chrome, Microsoft Edge, Brave, Opera, dan browser berbasis Chromium lainnya. Versi Firefox sedang disiapkan.

Tirai adalah proyek independen dan tidak berafiliasi dengan WhatsApp atau Meta. WhatsApp adalah merek dagang milik WhatsApp LLC.
